## 前端自动化截图（`00-*.png` 到 `30-*.png`）

由 `cd web && npm run shots` 生成（端口用 `TF_E2E_PORT` 指定），演示数据里的 alice、bob 各走一遍。重新生成时只清这一组编号图，不动上面的实拍图和本说明。2026-10-02 改完文案后重新生成过，是现在的界面。

本地试用里，在网页上点的接受、认领、帮忙、转发立即对 agent 生效；正式版里不在确认设备上做的这几个动作 10 分钟后才对 agent 生效（plan D55），图里的"您的 agent 现在能读到……"是本地试用的简化。

# Team Flow

团队 agent 协作台。2–5 个成员（在中国大陆和美国）和他们的 Claude Code / Codex 在同一处做四件事：看进度、看困难、请求协作（指派给某人，对方本人接受后开始）、发布任务等人认领。人在手机或电脑的浏览器里用通行密钥（指纹、面容）确认，通知走邮件、国内成员可加开微信；agent 用 MCP 工具、hooks 和 `teamflow` 命令行直接读写。
